# E83.8.5.4 Source Review

The MICCAI 2025 paper was reviewed at `https://papers.miccai.org/miccai-2025/paper/5129_paper.pdf`. It defines the interactive multi-relation graph, GFR graph convolution, CAM/PEN/RES prompt path, GraphConstructLoss and ALoss reporting. The author repository is pinned to commit `ba3b9446fa451fde6864d6555bdf324de0c4b64a`. The SABER repository and TADPOLE history repository were checked online. SABER references are `c7e2edbb8c56bdfc416b708da0ec6d743b0ed7d4`, `912a3ece628f818cec7525fe6323350f5a06e27e`, and `ae225e5135046d1d9622968b7d011f6aa55fa60d`.

The requested E83.8.5.2 and E83.8.5.3 source identities were checked in the `tangaii/sp` history repository at commits `21e53cf1e003cc23eacdb8e09bbe471f9fa08bd8` and `a8d8bed17f32fd07d2f1c9c77c4b01c38f0afc80`. GitHub raw text SHA-256 checks are recorded in `source_manifest.json`. E83.8.5.2 `code/run_e8385.py`, `code/common/fidelity_model.py` and `code/common/source_runtime.py` match the copied snapshot. E83.8.5.3 `code/run_e83853.py` and `code/relation_sampling.py` were retrieved and checked for provenance. The E83.8.5.3 server directory was not opened as a runtime dependency.

The six-modality path is taken from the copied E83.8.5.2 archive. `code/common/fidelity_model.py:455-543` retains the SignedDARG core, relation BCE at `0.05`, conditional adversary at `0.01`, preservation at `0.01`, GRL scale `0.03`, original graph support, signed positive/negative edges and the direct message. `code/common/fidelity_model.py:693-798` retains GFR/CAM/DPSL integration, frozen prompt loading and the Native/Full switch. `code/common/source_runtime.py:119-220` binds the archived DARG relation and Positive-DCR definitions to six TADPOLE modalities and COGNITIVE_TEST index 4.

The historical second-modality GFR overwrite is retained in `code/common/fidelity_model.py:120-183`. The source `code/common/run_e833.py:79-94` provides the historical warmup pair path and GraphLearn support extraction. The warmup loop in `code/run_e83854.py:441-486` uses the original graph path for epochs 1-10. `code/run_e83854.py:1176-1261` validates the historical warmup, optimizer state, RNG and spectral state before formal training.

The only formal training change is the relation tensor replacement performed after warmup in `code/run_e83854.py:1264-1430`. `code/relation_sampling.py` constructs canonical unique patient pairs, six fixed category quotas, T2/T3 frozen cognitive support prefixes and T4 diagnosis-internal exposure balancing. Its local NumPy generators are checked against the model RNG state. No test label is read by the sampler.

The paper's ALoss graph-alignment objective, the author implementation's logged ALoss, and S02 Paper-ALoss training are distinct. In the author `simple-2` path, `code/sources/history_base/model.py:127-151` obtains `ALoss` from MessagePassing0 and prints it as the third `trn-loss-MF`, while the backward total at `:141-145` is only `cls_loss + all_graph_loss`. The corresponding source `code/sources/history_base/network.py:247-274` computes the unsquared Frobenius norm observation. S02's frozen Paper-ALoss implementation at `code/run_e83854.py:299-325` uses the squared Frobenius difference on the train-train normalized graph block, with the configured coefficient `0.01`. `author_unsquared_aloss` at `:494-512` preserves the author's third log value separately. The actual S02 backward path at `:1454-1506` includes the configured Paper-ALoss within historical graph supervision plus DARG objectives, and the DPSL shared-parameter objective is applied by the subsequent optimizer path. The three repeated author-format fields remain observations, not three total-loss terms.
