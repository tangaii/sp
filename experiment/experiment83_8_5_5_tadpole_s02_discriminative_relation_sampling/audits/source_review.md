It defines the interactive multi-relation graph, GFR graph convolution, CAM/PEN/RES prompt path, GraphConstructLoss and ALoss reporting. The author repository is pinned to commit `ba3b9446fa451fde6864d6555bdf324de0c4b64a`. The SABER repository HEAD is `c7e2edbb8c56bdfc416b708da0ec6d743b0ed7d4`. The requested E83.8.5.2 and E83.8.5.3 source identities were checked in the `tangaii/sp` history repository at commits `21e53cf1e003cc23eacdb8e09bbe471f9fa08bd8` and `a8d8bed17f32fd07d2f1c9c77c4b01c38f0afc80`. E83.8.5.3 `code/run_e83853.py` and `code/relation_sampling.py` were retrieved and checked for provenance. The E83.8.5.3 server directory is not opened or imported as a runtime dependency. The E83.8.5.4 public source at commit `49fb7861bdc33841151b4682d273dbf92cebaac1` was separately examined, including `code/run_e83854.py`, `code/relation_sampling.py`, `code/common/fidelity_model.py`, and `code/common/run_e833.py`.

The six-modality path is taken from the copied E83.8.5.2 archive. `code/common/fidelity_model.py:455-543` retains the SignedDARG core, relation BCE at `0.05`, conditional adversary at `0.01`, preservation at `0.01`, GRL scale `0.03`, original graph support, signed positive/negative edges and the direct message. `code/common/fidelity_model.py:693-798` retains GFR/CAM/DPSL integration, frozen prompt loading and the Native/Full switch. `code/common/source_runtime.py:119-220` binds the archived DARG relation and Positive-DCR definitions to six TADPOLE modalities and COGNITIVE_TEST index 4.

The historical second-modality GFR overwrite is retained in `code/common/fidelity_model.py:120-183`. The source `code/common/run_e833.py:79-94` provides the historical warmup pair path and GraphLearn support extraction. The warmup loop in `code/run_e83855.py:441-486` uses the original graph path for epochs 1-10. `code/run_e83855.py:1190-1276` validates the historical warmup, optimizer state, RNG and spectral state before formal training.

The only formal training change is the relation tensor replacement performed after warmup in `code/run_e83855.py:1320-1366` and consumed at epoch 11 in `code/run_e83855.py:1438-1442`. `code/relation_sampling.py` constructs one shared deterministic random base from each genuine S02 fold six-relation quota, then applies registered 10% difficulty positions and randomized cognitive-graph positions. U1 uses the shared placebo substitutions. U2 selects MCI-MCI candidates from the 10th-30th similarity percentiles. U3 and U4 select NC-MCI and MCI-AD candidates from the 70th-90th percentiles. U5 applies both boundary selections. U6 selects randomized legal pairs from frozen epoch-10 COGNITIVE_TEST GraphLearn support with the documented deterministic shortfall fallback. All pairs are canonical unique patient pairs and local NumPy generators are checked against the model RNG state. No test label is read by the sampler.

The paper's ALoss graph-alignment objective, the author implementation's logged ALoss, and S02 Paper-ALoss training are distinct. In the author `simple-2` path, `code/sources/history_base/model.py:127-151` obtains `ALoss` from MessagePassing0 and prints it as the third `trn-loss-MF`, while the backward total at `:141-145` is only `cls_loss + all_graph_loss`. The corresponding source `code/sources/history_base/network.py:247-274` computes the unsquared Frobenius norm observation. S02's frozen Paper-ALoss implementation at `code/run_e83855.py:299-325` uses the squared Frobenius difference on the train-train normalized graph block, with the configured coefficient `0.01`. `author_unsquared_aloss` at `:494-512` preserves the author's third log value separately. The actual S02 backward path at `:1454-1506` includes the configured Paper-ALoss within historical graph supervision plus DARG objectives, and the DPSL shared-parameter objective is applied by the subsequent optimizer path. The three repeated author-format fields remain observations, not three total-loss terms. The new code does not add a loss, parameter, graph edge, or optimizer branch.

H0 replays the read-only R0 archive and H1 replays the read-only E83.8.5.2 S02 archive. Checkpoint bytes are never copied into the source tree. The E83.8.5.3 server directory is not a runtime dependency.


The reference TADPOLE author log is `logs/H0_result_Tadpole.txt` and `logs/H1_result_Tadpole.txt`, byte-identical copies of their true historical log sources. Epoch rendering for U1-U6 uses recorded training scalars only. The local implementation source archive is copied under `code/sources`; no ABIDE root model or checkpoint is read or modified.
